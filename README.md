# Assembly Programming

A 32-bit x86 assembly program demonstrating integer division and low-level console I/O.

## Features

- Signed and unsigned division using processor instructions
- quotient and remainder
- hexadecimal input and output

## Technology stack

x86 assembly, MASM, Irvine32.

## Getting started

Review `assembler/Projekt_kod_ASK.txt` and use a 32-bit MASM environment configured with Irvine32. Save the source as an `.asm` file for assembly. The implementation uses processor division instructions.
